# 🛡️ RentShield AI

### Check Before You Pay.

RentShield AI is an AI-powered rental scam detection website designed to help users identify suspicious rental listings before paying deposits or sharing sensitive personal information.

The platform analyzes rental listings using multiple indicators such as rental price, locality benchmarks, listing descriptions, text reuse, image metadata, and common rental scam patterns.

---

## 🚨 Problem Statement

Online rental platforms contain both genuine and fraudulent property listings.

Rental scammers may use:

- Unusually low rental prices
- Reused property photographs
- Copied rental descriptions
- Fake property information
- Urgent payment requests
- Advance-payment pressure
- Misleading rental details

Many users realize that a listing is fraudulent only after they have already transferred money.

**RentShield AI provides an early warning system to help users identify potential risks before making a payment.**

---

## 💡 Our Solution

RentShield AI allows users to submit rental listing information and analyzes it for potential scam indicators.

The system combines multiple signals to generate a risk assessment and explain the factors that may make a listing suspicious.
